# Academic media delivery — proposed design
No deployment or storage changes authorized by this document.
Use server-resolved asset IDs, authenticated identity, verified course entitlement and explicit audience classification before issuing short-lived signed URLs for private objects. Never accept arbitrary bucket/path from clients. Resolve canonical object references from trusted records; reject missing or ambiguous classification. Instructor keys require separate staff authorization. Assignment access requires ownership or assigned evaluator authorization. Public branding must be explicitly classified separately. Do not persist signed URLs or log tokens; use private/no-store responses. Signed links are bearer credentials until expiry; propose five-minute initial lifetime, subject to playback/download testing.
Inventory upload, preview, download, video, assignment and administrative paths, including direct object URLs and external hosts. Preserve object keys and content. Test disposable fixtures for authorized access, cross-user denial, expired links, draft and instructor-only denial, enrollment and membership expiry, upload and video range compatibility. Verify actual storage policies and direct URL denial before release. No automatic certification changes.
Rollout requires application compatibility, private ACL backup, separately approved maintenance window and post-change verification. Prefer forward repair over restoring public access. No paid provisioning or production changes.
